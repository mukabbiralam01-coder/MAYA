# Zoya AI Assistant - Android Studio Project (APK Ready)

Ye complete Android Studio Kotlin project hai jisme Zoya AI Assistant native Android app ke roop mein chalti hai!

---

## 📱 Features (Native Android Integration)
1. **Gemini Live 3.1 Duplex Voice**: Microphone audio auto-granted bina kisi permission popup ke.
2. **Torch / Flashlight Control**: Real hardware CameraManager se flashlight on/off hoti hai.
3. **Vibration / Haptics**: Phone ko vibrate karta hai patterns ke saath.
4. **"Don't Touch My Phone" Motion Guard**: Accelerometer sensor se phone hilane par siren aur voice warning shout karta hai!
5. **Battery Telemetry**: Real battery level aur charging detection.
6. **WhatsApp & Phone Call**: Direct phone call aur WhatsApp message launcher.
7. **Offline Assets Bundled**: Saara web app bundle `assets/www/` mein shamil hai, aur online live server par bhi connect hota hai.

---

## 🚀 How to Open & Build APK in Android Studio:
1. **Unzip** karein: `zoya-android-project.zip` ko extract karein.
2. **Open in Android Studio**:
   - Android Studio kholein -> **Open** -> `android` folder select karein.
   - Gradle sync automatically complete ho jayega.
3. **Build APK**:
   - Menu bar mein jayein: **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
   - 1-2 minute mein APK generate ho jayegi: `app/build/outputs/apk/debug/app-debug.apk`.
4. **Install on Phone**:
   - Phone ko USB se connect karein aur Run button dabayein, ya `.apk` file mobile mein bhej kar install karein!
